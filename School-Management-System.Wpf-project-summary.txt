Startup and application flow:
- Entry point: App.xaml / App.xaml.cs
- App.OnStartup:
  - sets ShutdownMode = OnExplicitShutdown
  - wires global exception handlers for Dispatcher, AppDomain, and TaskScheduler
  - initializes runtime database connection mode from command-line args
  - executes RunLoginShellLoop()
  - login loop:
    - constructs LoginViewModel with LoginConnectionService
    - displays LoginWindow
    - if the dialog closes without a valid authenticated user, shuts down cleanly
    - if login succeeds:
      - creates AppBootstrapper for current mode
      - starts UserSession for authenticated user
      - opens MainWindow and assigns it as Application.MainWindow
      - after window closes, ends UserSession
      - if logout was requested, loop continues; otherwise app shuts down

AppBootstrapper responsibilities:
- Builds runtime configuration and services for WPF using the legacy WinForms data layer
- Reads database configuration and applies current connection mode
- Tests DB connection and throws if it fails
- Ensures schema is current via SchemaMigrationRunner.EnsureCurrent(database)
- Creates data access adapters and services:
